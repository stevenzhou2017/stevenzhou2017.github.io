### 1. 引言：为什么选择贝叶斯建模？

在数据科学和工程实践中，我们经常面对**小样本、不确定性高、需要融入领域知识**的场景。传统频率学派（Frequentist）方法擅长给出“点估计”和p-value，但往往难以自然地量化预测不确定性或融合先验信息。

**贝叶斯建模**的核心哲学是：**一切皆概率**。它把参数视为随机变量，通过“先验信念 + 数据更新 → 后验信念”的方式进行推理，最终得到完整的**后验分布**，而非单一数值。

**贝叶斯 vs 频率学派核心对比**：

| 维度             | 频率学派（Frequentist）                  | 贝叶斯（Bayesian）                          | 实际影响 |
|------------------|------------------------------------------|---------------------------------------------|----------|
| 参数本质         | 固定未知常数                             | 随机变量（有分布）                          | 贝叶斯可直接给出参数概率 |
| 不确定性表达     | 置信区间（长期频率解释）                 | 可信区间（当前信念概率）                    | 贝叶斯更直观 |
| 先验信息         | 不使用（或隐含）                         | 显式融入领域知识                            | 贝叶斯适合小样本 |
| 模型比较         | AIC/BIC、交叉验证                        | WAIC、LOO-CV、Bayes Factor、模型平均        | 贝叶斯工具更丰富 |
| 预测               | 点预测 + 区间                           | 完整预测分布（含不确定性）                  | 贝叶斯决策更稳健 |
| 计算复杂度       | 通常较低                                 | 较高（需采样）                              | 现代工具已大幅降低门槛 |

**一句话总结**：频率学派问“这个参数在无限重复实验中是多少？”；贝叶斯问“在当前数据和先验下，这个参数最可能在什么范围？”

### 2. 贝叶斯建模的标准流程（五步法）

#### 步骤1：定义模型（先验 + 似然）
- **似然函数**：描述数据如何由参数生成（例如高斯分布）。
- **先验分布**：对参数的初始信念（可弱、可强、可截断正态）。

#### 步骤2：计算/采样后验
- 理论上：后验 ∝ 似然 × 先验。
- 实际：使用 **MCMC**（如NUTS）、**变分推断**，或小样本下的 **Bootstrap 近似**。

#### 步骤3：后验诊断与可视化
- 收敛性（trace plot、R-hat）
- 参数后验分布（直方图、pairplot）
- 参数相关性（热图）

#### 步骤4：模型选择、比较与平均
- 信息准则（WAIC、LOO-CV、DIC）
- Bayes Factor
- **模型平均（Model Averaging / Stacking）**

#### 步骤5：后验预测与决策
- **PPC（Posterior Predictive Check）**：用后验生成新数据，对比真实数据。
- 预测区间 + 不确定性分解。

### 3. 实战例子：电池 SOH 与低谷电压的高斯建模

**问题背景**：锂电池老化后，低谷电压与 SOH 呈非单调“山峰”关系。我们用4个实测点建模，目标是预测不同 SOH 下的电压并量化不确定性。

**数据**：
- SOH (%)：100, 90.65, 83.19, 80.66
- 低谷电压 (V)：2.7103, 2.7501, 2.7333, 2.7266

**候选模型**：
1. **高斯钟形模型**：
   $$
   V = A \exp\left( -\frac{(SOH-\mu)^2}{2\sigma^2} \right) + b
   $$
   - A：峰值幅度（早期老化效应）
   - μ：峰值位置（≈90.3%，老化转折点）
   - σ：峰宽
   - b：基础电压

2. **二次多项式**（对比基准）：简单但峰值捕捉较弱。

**先验设置**（强截断正态示例）：
- 基于物理知识：μ 应在 87~93.5 附近，A 在合理幅度范围等。

### 4. 模型选择与评估工具详解（附可视化）

#### 1. WAIC 与 LOO-CV
- **WAIC**：计算简单，适合快速比较。
- **LOO-CV (PSIS-LOO)**：更稳健，推荐首选。能给出 Pareto k 诊断（k<0.5 优秀）。

**实际结果**（强先验下）：
- 高斯模型：WAIC ≈ 28–32，LOO ≈ 28–33（优于二次多项式）
- 有效参数数 p_waic ≈ 3.1–3.5（合理）

#### 2. PPC（后验预测检验）—— 必做可视化诊断

PPC 是检验模型是否“像真数据”的最直观工具：从后验中抽取参数，生成大量“假数据”，对比真实数据分布。

**典型 PPC 图特征**（高斯模型）：
- 红色：真实数据密度（带峰值）
- 紫色细线：多条复制数据
- 蓝色粗线：复制数据平均
- **好模型**：蓝色与红色高度重叠，峰值位置和宽度匹配良好。

#### 3. 参数后验可视化（更多图表示例）
- **Pairplot（4×4）**：展示参数边际分布 + 联合分布（A 与 μ 呈负相关）。
- **相关性热图**：原始 vs 固定参数后对比（固定 μ 显著降低 A-σ 相关性）。
- **不同先验强度对比散点图**：弱先验 → 散点分散；强先验 → 高度集中（相关性下降）。

这些图帮助我们理解**参数依赖性**和**先验的影响**。

### 5. 模型平均（Model Averaging）实战代码

当多个模型都有一定合理性时，不要只挑“最好”的，而是**加权平均**，权重基于 WAIC/LOO。

```python
import numpy as np

# 假设已有两个模型的后验 log_lik_matrix_gauss 和 log_lik_matrix_quad
# 计算 WAIC（简化）
def compute_waic(log_lik_mat):
    lppd = np.sum(np.log(np.mean(np.exp(log_lik_mat), axis=0)))
    p_waic = np.sum(np.var(log_lik_mat, axis=0))
    return -2 * (lppd - p_waic)

waic_g = compute_waic(log_lik_matrix_g)  # 高斯
waic_q = compute_waic(log_lik_matrix_q)  # 二次

# 模型权重（基于 WAIC，类似 stacking）
delta_waic = waic_g - waic_q
weight_g = 1 / (1 + np.exp(delta_waic / 2))   # 简化 softmax
weight_q = 1 - weight_g

print(f"高斯模型权重: {weight_g:.3f}")
print(f"二次模型权重: {weight_q:.3f}")

# 模型平均预测（示例）
new_soh = np.array([95, 85, 75])
pred_g = np.mean([gaussian(new_soh, *p) for p in boot_params_g], axis=0)
pred_q = np.mean([quad(new_soh, *p) for p in boot_params_q], axis=0)
pred_avg = weight_g * pred_g + weight_q * pred_q

print("模型平均预测:", pred_avg)
```

**优势**：模型平均通常比单一“最佳”模型预测性能更好，且自动处理模型不确定性。

### 6. 频率学派 vs 贝叶斯：更深入对比

- **点估计 vs 分布**：频率学派给“最佳值”，贝叶斯给完整分布 + 可信区间。
- **p-value vs 概率**：p-value 是“如果原假设为真，出现当前数据或更极端的概率”；贝叶斯直接给出“参数在某个区间的概率”。
- **先验**：频率学派隐含“无信息先验”；贝叶斯显式使用，可正则化小样本。
- **模型选择**：频率学派常用 AIC/BIC；贝叶斯用 WAIC/LOO，更直接面向预测。
- **计算**：频率学派通常更快；贝叶斯需要采样，但现代工具（PyMC + ArviZ）已非常友好。

**何时选贝叶斯？**
- 需要量化不确定性
- 小样本或需要融入专家知识
- 多模型比较/平均
- 复杂层次结构

### 7. 实用工具栈与最佳实践

**推荐工具**：
- **建模**：PyMC（最成熟）或 NumPyro / Stan
- **诊断与比较**：ArviZ（LOO、WAIC、PPC、模型比较一站式）
- **可视化**：seaborn + matplotlib（pairplot、PPC、热图）
- **小样本近似**：Bootstrap + 点式对数似然（本文使用方式）

**最佳实践 checklist**：
1. 始终做 PPC。
2. 报告 WAIC/LOO + Pareto k 诊断。
3. 尝试不同先验强度，观察稳健性。
4. 考虑模型平均而非单一选择。
5. 用 ArviZ 进行模型比较和权重计算。

### 8. 结语与行动建议
